ProdTracker User Manual

Version 2.0

1. Setting Up Technicians & DPO

The foundation of the system is accurate Production Objectives.

Setting the Daily Production Objective (DPO)

Navigate to Manage > Team Members and click Edit on a technician. You have two ways to set their daily goal:

  • Manual Mode (Best for New Hires): Select "Set DPO Manually" and enter a fixed number (e.g., 8.0 hours/day).
  • Calculated Mode (Best for Established Techs): Select "Calculate DPO (Historical)" and enter their last 10 weeks of data (Total FRH, Days Worked, Time Off). Enter a Lift % target (e.g., 115 for a 15% increase) to auto-calculate their goal.

2. Scheduling & Communication

Generating the Month

Go to Manage > Generate Schedules. Select the Team, Date Range, and Working Days. The system automatically marks system holidays (Thanksgiving, Christmas, etc.) as non-productive.

The Printable Calendar 🖨️

Navigate to Manage > Standard Team Schedules. Press Ctrl + P to print a clean schedule for the shop bulletin board.

3. The Daily Route Sheet

The command center for Advisors and Techs.

Workflow

Use the "Add RO" row at the bottom for new jobs. Click the Status Button to move cars through the shop flow (Dispatch → Inspection → Approval → Parts → Service → Ready).

Alerts
  • Red Time: Vehicle is past promised time.
  • Yellow Time: Vehicle due within 2 hours.
  • Yellow Note Icon: Unread internal note.

4. Logging Hours

Accurate logging drives the Financial Dashboard.

Method A: Quick Log

Best for "In the Flow". Click the green Stopwatch icon on the Route Sheet. A popup appears pre-filled with the RO info. Enter Sold/Actual hours and click Save.

Method B: Detailed Log

Best for End-of-Day. Navigate to "Work Logs" to enter detailed line items or review your daily efficiency. This view highlights high performers in Green.

5. Live Production Display 📺

Access this via Production Display in the menu. Display this on a shop monitor.

  • Real-Time Bars: Shows hours flagged vs. Daily Goal.
  • Color Coded: Red (Behind), Yellow (On Track), Green (Goal Met).

6. Financial Tools

Forecasting

The Dashboard calculates projected Month-End Gross Profit based on scheduled productive days and current tech performance.

Reconciliation (Audit)

Go to Manage > Reconcile Work Logs. Upload your CDK Payroll CSV. The system compares ProdTracker logs vs. DMS payments to find missing tickets or over-reporting.

Opportunity Calculators

Use the Calculators menu to run "What-If" scenarios on MPI upsells, Shop Capacity, and Appointment Volume.
